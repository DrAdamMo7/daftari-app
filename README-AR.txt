دفتري 1.8 — نسخة الويب / الآيفون (PWA)

1) ارفع محتويات هذا المجلد كما هي على أي استضافة HTTPS
   (Cloudflare Pages / Netlify / GitHub Pages). لازم HTTPS عشان التثبيت والعمل بدون إنترنت.
2) على الآيفون: افتح الرابط بـ Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
   بيظهر بشعار دفتري وبيفتح بملء الشاشة مثل أي تطبيق.
3) على الكمبيوتر/أندرويد: Chrome أو Edge ← أيقونة «تثبيت» في شريط العنوان.

ملاحظة: التخزين محلي في المتصفح (IndexedDB). على الآيفون لو ما استخدمت التطبيق مدة طويلة قد يمسح Safari البيانات، فاعمل نسخ احتياطي/تصدير للمهم.
